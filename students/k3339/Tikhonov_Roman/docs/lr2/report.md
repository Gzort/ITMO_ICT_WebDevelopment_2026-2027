# ЛР2. Простой сайт на Django

## Цель работы

Овладеть практическими навыками и умениями реализации web-сервисов средствами
Django: паттерн MVC (model — view — template), ORM, формы, авторизация,
разграничение прав, работа с СУБД PostgreSQL.

## Задание

Вариант 2 — «Доска домашних заданий». Реализовать сайт, хранящий информацию о
домашних заданиях (предмет, преподаватель, дата выдачи, период выполнения, текст
задания, информация о штрафах) и обеспечивающий регистрацию пользователей,
просмотр заданий, сдачу заданий в текстовом виде, выставление оценок через
Django-admin и таблицу оценок всего класса в клиентской части.

## Программное обеспечение

- Python 3.12.6, Django 5.2 LTS, psycopg2-binary 2.9.13
- Практики 2.1–2.3 — SQLite (по методичке); лабораторная работа — PostgreSQL 18
- Windows 10, PyCharm / командная строка



## Результат

Реализованы все требования варианта. Выполнены:
