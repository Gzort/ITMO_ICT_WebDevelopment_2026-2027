# Лабораторная работа 2. Доска домашних заданий (вариант 2)

## Общая характеристика

Сайт для класса: учителя публикуют домашние задания, ученики сдают их в
текстовом виде и видят таблицу оценок всего класса. Роли: ученик — обычный
пользователь, учитель — пользователь с флагом `is_staff`.

Порядок работы с сайтом выглядит так: новый ученик регистрируется сам, вводит
логин, имя, фамилию и пароль и сразу попадает на доску заданий. Учитель
заводится администратором и уже имеет доступ к панели Django-admin. Анонимный
посетитель видит только страницы входа и регистрации — весь остальной
функционал закрыт авторизацией.

## Модель данных

О задании хранится: предмет, преподаватель, дата выдачи, срок выполнения
(период), текст задания, информация о штрафах. Сдача связывает ученика и
задание, оценку ставит учитель.

```python
from django.conf import settings
from django.db import models


class Subject(models.Model):
    name = models.CharField(max_length=100, unique=True)

    def __str__(self):
        return self.name


class Homework(models.Model):
    subject = models.ForeignKey(Subject, on_delete=models.CASCADE, related_name="homeworks")
    teacher = models.ForeignKey(settings.AUTH_USER_MODEL, on_delete=models.CASCADE, related_name="homeworks")
    issued = models.DateField(verbose_name="дата выдачи")
    due = models.DateField(verbose_name="срок выполнения")
    text = models.TextField(verbose_name="текст задания")
    penalties = models.TextField(verbose_name="штрафы", blank=True)

    def __str__(self):
        return "{} ({})".format(self.subject, self.issued)


class Submission(models.Model):
    homework = models.ForeignKey(Homework, on_delete=models.CASCADE, related_name="submissions")
    student = models.ForeignKey(settings.AUTH_USER_MODEL, on_delete=models.CASCADE, related_name="submissions")
    text = models.TextField()
    submitted_at = models.DateTimeField(auto_now=True)
    grade = models.PositiveSmallIntegerField(null=True, blank=True)

    class Meta:
        unique_together = ("homework", "student")

    def __str__(self):
        return "{} - {}".format(self.homework, self.student)
```

Ограничение `unique_together` запрещает две сдачи одного ученика по одному
заданию — повторная отправка обновляет текст (обновление доступно, пока
задание не оценено, оценка при этом сохраняется).

Предмет вынесен в отдельную таблицу-справочник: названия не дублируются в
заданиях, и по предмету удобно строить фильтр. Оценка сделана необязательной
(`null=True`) — сдача существует с момента отправки, а оценка появляется
только после проверки учителем.

## Страницы и адресация

| URL                             | Назначение                          | Доступ        |
|---------------------------------|-------------------------------------|---------------|
| `/`                             | список заданий                      | после входа   |
| `/homework/<id>/`               | карточка задания, сдача текстом     | после входа   |
| `/grades/`                      | таблица оценок класса               | после входа   |
| `/homework/create/`             | создание задания                    | только учитель|
| `/homework/<id>/submissions/`   | сдачи всех учеников, оценка         | только учитель|
| `/accounts/register/`, `/accounts/login/`, `/accounts/logout/` | регистрация, вход, выход | все |
| `/admin/`                       | Django-admin (оценки, данные)       | только staff  |

## Функционал ученика

Ученик после регистрации и входа может:

- просматривать домашние задания по всем дисциплинам: предмет, учитель, дата
  выдачи, срок выполнения, текст задания и штрафы;
- искать задания по тексту и по названию предмета, отфильтровать доску по
  одному предмету, листать страницы списка;
- открыть карточку задания и сдать его в текстовом виде — обычным текстом или
  со ссылкой на файл (например, документ на Google Drive);
- пересдать задание до проверки: повторная отправка обновляет текст сдачи,
  а не создаёт новую запись;
- видеть статус каждой своей работы в списке — «Сдано», пока работа не
  проверена, и оценку, как только учитель её поставил;
- смотреть таблицу оценок всего класса: кто что сдал и что уже проверено.

Чего ученик делать не может: создавать и редактировать задания, видеть чужие
сдачи, заходить в Django-admin. Ссылок на эти действия у него в меню нет, а
при переходе по адресу напрямую сайт перенаправляет его на страницу входа.

## Функционал учителя

Учитель (пользователь с `is_staff`) дополнительно может:

- публиковать новые домашние задания прямо на сайте: предмет, даты, текст,
  условия штрафов — без обращения к админке;
- видеть в списке количество сдач по каждому заданию и переходить к ним;
- на странице сдач читать работы всех учеников с текстом и временем отправки;
- выставлять оценку прямо на странице сдач или через Django-admin — как
  требует задание варианта; в админке для этого настроены фильтры по предмету
  и оценке и поиск по фамилии ученика;
- пользоваться всей панелью Django-admin: задания, предметы, сдачи,
  пользователи класса.

Таким образом, учитель видит и делает на сайте больше, чем ученик, — это и
есть разграничение прав в клиентском интерфейсе, а не только через админку.

## Клиентская часть

Список заданий — главная страница. Задания выводятся таблицей от новых к
старым, по пять на страницу; под таблицей — пагинация с номерами страниц.
Над таблицей — форма фильтра: выпадающий список предметов и строка поиска.
Фильтр и поиск отправляются методом GET, поэтому адрес страницы с фильтром
можно сохранить или переслать. При переходе по страницам параметры фильтра
сохраняются в ссылках пагинации — фильтр не сбрасывается.

Карточка задания показывает все его поля и блок «Моя сдача»: у ученика там
форма с текстом работы и кнопкой («Сдать задание» или «Обновить сдачу» в
зависимости от того, сдавал ли он раньше), у учителя — ссылка на работы всего
класса. Ссылки в тексте сдачи, например на Google Drive, отображаются
кликабельными.

Регистрация и вход построены на стандартных механизмах Django: форма
регистрации проверяет пароль по правилам (минимум восемь символов, не только
цифры), после регистрации пользователь сразу считается вошедшим; выход
доступен из меню любой страницы.

## Разграничение прав

Права разделены на двух уровнях. В шаблонах навигация и блоки страниц
настраиваются условием `{% if user.is_staff %}` — ученик просто не видит
лишних ссылок и форм. В представлениях стоят проверки доступа: анонимов
возвращает декоратор `login_required`, а на учительские страницы (создание
задания, страница сдач, сохранение оценки) пускает только пользователь с
`is_staff`. Шаблонная проверка отвечает за удобство, реальная граница —
в представлениях.

## Таблица оценок класса

Строки — ученики (пользователи без `is_staff`), столбцы — задания; оценки
собираются в словарь и выводятся как «журнал» (пустая клетка — работа не сдана
или не оценена). Заголовок столбца содержит предмет и дату выдачи и ведёт на
карточку задания, поэтому с таблицы удобно провалиться в условие любой работы.
