# ЛР1. Сетевые взаимодействия на сокетах

## Цель работы

Изучить принципы межсокетного взаимодействия в вебе и реализовать базовую
архитектуру «клиент — сервер» на языке Python с использованием модуля `socket`.

## Задания

| № | Тема                                 | Протокол        | Страница          |
|---|--------------------------------------|-----------------|-------------------|
| 1 | Обмен сообщениями                    | UDP             | [Отчёт](task1.md) |
| 2 | Вычисления (площадь параллелограмма) | TCP             | [Отчёт](task2.md) |
| 3 | Раздача HTML-страницы                | HTTP            | [Отчёт](task3.md) |
| 4 | Многопользовательский чат            | TCP + threading | [Отчёт](task4.md) |
| 5 | Веб-сервер (журнал оценок)           | HTTP GET/POST   | [Отчёт](task5.md) |

## Общие сведения

Все программы построены по схеме «клиент — сервер» и используют только стандартную
библиотеку Python. Адрес взаимодействия — `127.0.0.1`, порты заданий — 8081–8085.
